# 复现示例

## 输入图片

`input/missing_hole01.jpg` 来自第二阶段的 PCB 缺陷数据集,是发布时实际用于在线
验收的原始图片。可直接在 `/ui/` 页面上传。

## 参考结果

- `output/yolo_sam_result.png`:YOLO 检出 3 处缺孔,SAM 生成红色分割掩膜。
- `output/deepseek_result.png`:同一次任务中视觉大模型的参考输出。

视觉大模型输出可能随 API 和时间变化;YOLO 部分在同一模型、阈值和输入下应保持稳定。
参考结果用于帮助验收人员判断页面、文件上传和结果下载是否正常,不用于替代重新运行。

## 在线复现

1. 打开 http://39.107.27.28/ui/
2. 使用交付说明中提供的演示账号登录。
3. 上传 `input/missing_hole01.jpg`。
4. 等待任务完成,检查左右两张结果图。
