# 项目计划

## 一、选题

**PCB 缺陷检测平台** —— 把第二阶段的双方案对比做成本地可操作的 Web 应用。

第二阶段已经完成工业 PCB 缺陷检测的两种方案:

- 传统方案:YOLO11n 检测 + SAM 2.1 分割(mAP50 0.956);
- 大模型方案:DeepSeek `deepseek-flash` 零样本判断。

本阶段不重新训练模型,而是复用这些能力,补上 **Web 层、异步任务、数据记录与部署**。

## 二、与考核思维导图的对应

| 思维导图要求 | 本项目落地 |
| --- | --- |
| FastAPI / Flask:接口设计、文件上传、参数处理、模型调用 | FastAPI 实现 `/api/jobs` 上传与查询接口 |
| SQLAlchemy:数据库增删改查 | SQLite + SQLAlchemy 记录每次检测任务 |
| Gradio / Streamlit:输入页面,并排展示两种方案 | Gradio 页面,上传后并排显示两种结果 |
| Linux:系统与命令行、SSH、依赖与排错 | 已部署到 Ubuntu 22.04 云服务器 |
| Docker:镜像与容器、Compose、数据挂载 | Dockerfile + Compose(web/worker/redis/nginx) |
| nginx:反向代理与静态资源 | nginx 反代 FastAPI,包含健康检查和动态重新解析 |
| 身份认证:JWT | 账号密码换取 token,受保护接口统一校验 |
| 消息队列:异步处理与结果返回 | Redis + RQ 队列;无 Redis 时退化为线程 |
| 复用第二阶段项目 | 直接使用第二阶段训练好的权重与推理逻辑 |
| 网页复现双方案对比 | 上传同一张图,并排展示 YOLO/SAM 与大模型结果 |
