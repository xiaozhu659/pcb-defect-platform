# 部署与验收

## 1. 准备文件

仓库不包含模型权重和密钥。运行前准备:

```text
models/yolo_best.pt
models/sam2.1_t.pt
.env
```

`.env` 参照 `.env.example`,至少填写:

```dotenv
DEEPSEEK_API_KEY=你的密钥
LLM_EFFORT=low
APP_USER=你的演示账号
APP_PASSWORD=你的演示密码
JWT_SECRET=足够长的随机字符串
```

不要把 `.env`、API Key 或 JWT Secret 提交到 GitHub,也不要录进演示视频。

## 2. 一键启动

```bash
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml ps
```

首次启动 Web 服务需要导入 Gradio,通常等待 10 到 30 秒。如果刚重建过 `web`
容器后 nginx 返回 502,重启 nginx 让其重新解析容器地址:

```bash
docker compose -f deploy/docker-compose.yml restart nginx
```

## 3. 验收检查

健康检查:

```bash
curl http://127.0.0.1/health
```

预期结果:

```json
{"status":"ok","queue":"redis"}
```

检查网页和未授权访问:

```bash
curl -I http://127.0.0.1/ui/
curl -i -X POST http://127.0.0.1/api/jobs
```

第二条应返回 `401`,证明 JWT 鉴权生效。

完整自动验收:

```bash
python scripts/smoke_test.py \
  --base-url http://127.0.0.1 \
  --image data/demo.jpg
```

脚本会依次检查健康接口、Gradio 页面、JWT 拦截、损坏图片拦截、任务执行和两张结果图。
账号密码默认从项目根目录 `.env` 读取,也可以在运行前设置
`APP_USER`、`APP_PASSWORD` 环境变量。

浏览器打开:

```text
http://服务器公网IP/ui/
```

登录后上传任意 JPG/PNG 图片。等待任务完成后应看到:

- 左侧:YOLO 检测框和 SAM 分割结果;
- 右侧:DeepSeek 判断结果;
- 上方文字:两种方案的数量、类别和耗时。

## 4. 日志与排错

```bash
docker compose -f deploy/docker-compose.yml logs --tail=100 web
docker compose -f deploy/docker-compose.yml logs --tail=100 worker
docker compose -f deploy/docker-compose.yml logs --tail=100 nginx
```

常见问题:

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| nginx 返回 502 | Web 尚未启动或地址缓存 | 等 Web 启动,再重启 nginx |
| 上传后接口返回 401 | 未登录或 token 过期 | 重新登录 |
| 结果缺少 SAM 掩膜 | SAM 权重路径错误 | 检查 `SAM_WEIGHTS` 和模型文件 |
| DeepSeek 报错 | API Key、余额或网络问题 | 查看 worker 日志,确认密钥未提交 |
| 服务器卡顿 | 2 GiB 内存偏紧 | 保持 `SAM_IMGSZ=256`,确认 2 GiB Swap 已启用 |
| 任务长期停在 queued/running | 队列或 Worker 中断 | 默认 30 分钟后自动标记失败,可用 `STALE_JOB_MINUTES` 调整 |

## 5. 从零复现

```bash
git clone https://github.com/xiaozhu659/pcb-defect-platform.git
cd pcb-defect-platform
cp .env.example .env
# 编辑 .env,并把两个模型权重放入 models/
docker compose -f deploy/docker-compose.yml up -d --build
curl http://127.0.0.1/health
```

验收者需要提供模型权重和 DeepSeek API Key;代码仓库本身不保存这两类敏感或大型文件。
