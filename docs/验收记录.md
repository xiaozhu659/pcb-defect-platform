## 1. 单元测试

```text
Ran 17 tests in 0.078s
OK
```

静态检查:

```text
uvx ruff check src tests scripts
All checks passed!
```

覆盖内容:

- 正常 PNG 图片可以保存;
- 损坏图片被拒绝并删除临时文件;
- 不支持的扩展名被拒绝;
- 扩展名与真实图片格式不一致时被拒绝;
- 超过大小限制的文件被拒绝;
- 图片像素总量超过限制时被拒绝。
- 两套方案都失败时,任务会被标记为 `failed`;
- 只有一套方案成功时,任务仍保留另一套结果并标记为 `done`。
- 页面下载的 PNG 结果会转换为 Gradio 可显示的 `PIL.Image`;
- 结果图响应异常时返回空值,不会把错误页面当作图片显示。
- 大模型返回无效 JSON 时抛出分析错误,不会伪造零缺陷结论;
- SAM 分割失败时,传统方案明确标记为“仅检测”;
- 传统方案分别记录 YOLO、SAM 和总耗时;
- 队列提交失败会立即把任务标记为 `failed`;
- 超过阈值的 `queued/running` 任务会自动判定为失败。
